# APEX : version de test

Runner rythmique à une touche : une panthère bioluminescente chasse des cerfs-lucioles dans une jungle noire.

**Jouer :** https://meta-h777.github.io/apex/

- **Maintenir** : se baisser et traquer (passer sous les branches roses).
- **Relâcher sur le temps fort** : bondir sur la proie. Parfait à ±45 ms, bien à ±90 ms.
- Monte le son : la chasse se joue au rythme.

Pour le développement : `?auto=1` dans l'adresse (ou la touche A) active le pilote automatique.

Version web en three.js du prototype Unity. Visuels générés avec Higgsfield.

## La Traque et la Fuite (v0.2)

À la moitié du territoire, les rôles s'inversent : tu deviens le cerf et la panthère te poursuit.
Mêmes gestes : maintenir pour passer sous les branches, relâcher sur les griffes au sol pour esquiver son bond.
Chaque bond raté lui fait gagner du terrain : au bout de trois, elle te rattrape. Les esquives parfaites te redonnent de l'avance.

Raccourcis de test : `?fuite=1` (commence en cerf), `?bascule=4` (bascule dès la 4e mesure).
